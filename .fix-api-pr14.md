# Fix report: alea-institute/ontokit-api#14

## Changes

- `SuggestionService._create_pr_directly` snapshots `user_id`, `user_name`, and
  `user_email` before the first allocation attempt and uses only those locals
  on every retry. If a collision caused a rollback, it refreshes the caller's
  `SuggestionSession` before returning so later reads in `_create_pr_for_session`
  and `auto_submit_stale_sessions` are not made against an expired ORM object.
- Added retry regression coverage using the existing expiry-simulating fixture
  pattern (not a real `AsyncSession`): the first flush raises `IntegrityError`,
  rollback expires the session object, and the second allocation succeeds with
  the snapshotted author values.
- Converted the Zitadel command from string form to list form without adding or
  removing arguments.
